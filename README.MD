# Calendar Logger

Приложение помогает вести календарь пользовательских метрик по дням и быстро просматривать историю записей.

# Ссылка на приложение

[https://dronov-dmitry.github.io/calendar-rate/](https://dronov-dmitry.github.io/calendar-rate/)

# Видео

[https://youtu.be/Tgjr4S5oZkc](https://youtu.be/Tgjr4S5oZkc)

# Цена

- Бесплатный тариф  : 2 метрики, 30 записей в месяц    : Free
- Стандартный тариф : 20 метрик, 200 записей в месяц   : 1 доллар в месяц
- Премиум тариф     : 100 метрик, 1000 записей в месяц : 5 долларов в месяц

## Что умеет приложение

- Регистрация и вход через Google.
- Просмотр своего профиля и текущего тарифа.
- Создание и перевыпуск персонального API Key для внешней отправки данных.
- Отправка метрик в календарь через API.
- Просмотр записей в таблице по выбранному месяцу.
- Навигация по месяцам вперёд и назад.
- Поиск по названию метрики.
- Визуальное разделение дней по неделям с понедельника по воскресенье.
- Подсветка выходных дней в календаре.
- Просмотр деталей записи в отдельном модальном окне.
- Удаление ошибочно добавленной записи.
- Просмотр истории платежей.
- Переход к оформлению подписки.

## Как используется API

- Пользователь получает персональный API Key в настройках доступа.
- После этого можно скачать готовый скрипт `send_metric.py`.
- Скрипт помогает отправлять новые значения метрик в календарь.
